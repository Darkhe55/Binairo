# 黑白 · Binairo

网页版「黑白」逻辑谜题（Binairo / Takuzu）。Vite + TypeScript + 原生 SVG，无框架。

## 玩法

- 每行、每列的**黑子数 = 白子数**
- **不能出现三个同色连排**（横竖都算）
- **任意两行 / 两列不得完全相同**

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5176
```

## 操作

| 操作 | 说明 |
|------|------|
| 左键点空格 | 循环：空 → 黑 → 白 → 空 |
| 右键点空格 | 反向循环 |
| 按住左键拖拽 | 连续涂同一个颜色 |
| 滚轮 / 中键拖拽 | 缩放 / 平移 |
| `Z` / `Shift+Z` | 撤销 / 重做 |
| `C` / `H` / `S` / `Esc` | 检查 / 提示一格 / 显示解 / 清空 |
| `R` / `L` | 随机抽题 / 逻辑解题 |

淡灰底是题目给定的固定格，不能改；你自己填的棋子外面带一圈虚线环。

## 功能

- 5 道内置题（6×6 到 12×12），全部经过**唯一解**校验
- 实时校验：三连画红框、黑白不均的行列淡红底、重复行列淡红底
- 提示一格 / 显示参考解（可撤销）、撤销重做按手势分组
- 自定义题板：自己摆给定格，「唯一解校验」一键确认有解且唯一
- 进度自动存 localStorage；悬停高亮、滚轮缩放、中键平移
