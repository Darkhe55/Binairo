# 黑白 Binairo

一个基于 Web 的黑白（Binairo / Takuzu）谜题游戏，原生 SVG 渲染，内置逻辑解题器接口。

## 在线体验

克隆后运行：

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5176`）。

## 游戏规则

在空白处填入黑白棋子：

- 每行、每列的黑子数等于白子数（各占一半）
- 不能出现三个同色连排（横向、纵向都算）
- 任意两行不能完全相同，任意两列也不能完全相同

## 操作

| 操作 | 说明 |
|------|------|
| 左键点空格 | 循环：空 → 黑 → 白 → 空 |
| 右键点空格 | 反向循环：空 → 白 → 黑 → 空 |
| 按住左键拖拽 | 连续填黑 |
| 按住右键拖拽 | 连续填白 |
| 滚轮 / 中键拖拽 | 缩放 / 平移 |
| `Z` / `Shift+Z` / `Y` | 撤销 / 重做 |
| `C` / `H` / `S` / `Esc` | 检查 / 提示一格 / 显示解 / 清空 |
| `R` / `L` / `M` | 随机抽题 / 逻辑解题 / 音效开关 |
| `0` / `+` / `-` | 视图复位 / 放大 / 缩小 |

淡灰底是题目给定的固定格，不能改（点击和拖拽都会跳过）；你自己填的棋子外面带一圈虚线环。

> 拖拽与点击用移动距离区分：按下后移动超过 8px 算拖拽填充，没超过就还是点击轮换。

## 功能

- **题库**：内置 5 道题，从 6×6 入门到 12×12 挑战，均校验唯一解
- **自定义题**：在侧边栏摆放给定格，"唯一解校验"一键确认有解且唯一
- **逻辑解题**：规则引擎接口已预留（`src/logic.ts`），UI 按钮已接通
- **音效特效**：落子播放弦振拨弦 + 形变抖动，连拍逐级抬音高
- **实时校验**：三连画红框、黑白不均的行列淡红底、重复行列淡红底
- **进度保存**：自动保存每道题的进度，刷新不丢失
- **撤销/重做**：按手势分组，一次拖拽涂写只需一步撤销
- **提示一格 / 显示解**、悬停高亮、滚轮缩放、中键平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage 存储进度

## 项目结构

```
src/
  main.ts         主逻辑：UI、交互、音效调度
  render.ts       SVG 棋盘渲染、命中检测、缩放度量
  logic.ts        逻辑解题规则引擎（预留接口）
  solver.ts       回溯求解器（唯一解校验）
  audio.ts        Web Audio 音效合成（拨弦 / 水滴）
  fx.ts           落子特效（弦振 / 形变 / 涟漪）
  puzzles.ts      题库加载
  puzzles-data.ts 静态题库数据（自动生成）
  state.ts        棋盘状态与行列读取
  validate.ts     解的合法性校验（三条规则）
  types.ts        共享类型
```
